# 📊 Student Data Analysis Project

## 📌 About the Project
This project focuses on analyzing student data using Python.
The dataset is cleaned, explored, and visualized to understand
students' marks and other information.

## 🎯 Project Objectives
- Load student data from a CSV file.
- Explore the dataset using Pandas.
- Identify and remove duplicate records.
- Calculate basic statistics.
- Create visualizations using Matplotlib.

## 📂 Dataset Information
The dataset contains the following columns:

| Column | Description |
|---|---|
| Name | Student's name |
| Age | Student's age |
| Marks | Student's marks |

## 🛠️ Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 🧹 Data Cleaning
- Checked for duplicate records.
- Removed duplicate rows.
- Verified the cleaned dataset.

## 📈 Data Visualization
The project includes three visualizations created with Matplotlib
to explore student data.

## 📁 Project Files
- `student_data.csv` — Dataset used for analysis.
- `week1_Analysis (1).ipynb` — Jupyter Notebook containing
  data analysis and visualizations.
- `README.md` — Project documentation.

## ▶️ How to Run the Project
1. Download or clone this repository.
2. Install the required libraries.
3. Open the Jupyter Notebook.
4. Run the notebook cells in order.

## 📦 Installation
Install the required libraries using:

```bash
pip install pandas numpy matplotlib jupyter
```

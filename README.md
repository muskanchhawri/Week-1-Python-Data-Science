# Student Data Analysis Project

## About the Project
This project analyzes student data using Python. It includes data cleaning, duplicate removal, data analysis, and data visualization.

## Dataset
The dataset contains student information, including:
- Name
- Age
- Marks

Duplicate records were removed during data cleaning.

## Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Visualizations
Three visualizations were created using Matplotlib to understand student data.

## Project Files
- `student_data.csv` — Student dataset
- `week1_Analysis (1).ipynb` — Jupyter Notebook containing analysis and visualizations
- `README.md` — Project documentation
